# 广场舞视频传送站 · 微信小程序客户端 (`miniprogram/`)

本目录为独立的原生微信小程序客户端，零第三方构建依赖，**直接用微信开发者工具导入本目录即可运行与上传代码**。

与原有的网页上传端 (`https://dance.lage.us.ci/`) 及电脑管理后台 (`https://dance.lage.us.ci/admin`) **共用同一套 Cloudflare Pages + R2 后端与存储桶**，网页版与管理后台保持 100% 不变。

---

## 一、核心技术特性

1. **8MB 分片二进制流式直传 (`/api/mp/*`)**：
   - 手机每次仅从闪存读取 `8MB` 分片至内存（即使上传 `500MB` 超清原画视频也绝不闪退 OOM）。
   - 单域名架构：仅请求 `config.js` 中的 `API_BASE_URL`（无需暴露 `r2.cloudflarestorage.com` 子域名），单分片网络抖动自动重试 3 次，取消上传自动清理云端未合并碎片。
2. **强制原画不压缩 (`sizeType: ['original']`)**：
   - 从手机相册选取视频后跳过微信本地耗时转码压缩，100% 保留原始高清画质并秒速开始传输。
3. **自动防息屏断连 (`wx.setKeepScreenOn`)**：
   - 上传期间自动保持手机屏幕常亮，防止大视频传输中途手机锁屏导致微信后台断网。
4. **微信转发卡片免密解锁**：
   - 已输入口令的用户点击底部 `📤 转发免密入口` 或右上角 `... -> 转发给朋友`，接收方在微信聊天中点击小程序卡片即可自动读取并保存口令，后续永久免密使用。
5. **内置微信隐私保护弹窗合规支持 (`__usePrivacyCheck__: true`)**：
   - 自动响应 `wx.onNeedPrivacyAuthorization`，满足微信真机 `chooseMedia` 隐私合规与代码审核要求。

## 二、复用原有小程序账号导入与发布步骤

### 第 1 步：导入微信开发者工具
1. 打开 **微信开发者工具** -> 点击 **导入项目**。
2. **目录** 选择：`e:\ispace\dance-transfer\miniprogram`（注意选 `miniprogram` 子文件夹，不要选外层根目录）。
3. **AppID** 下拉选择您现有的小程序 AppID（即之前 `bounce-literacy` 所在的小程序账号）。
4. 本地调试时：在开发者工具右上角 **详情 -> 本地设置** 中，勾选 **“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”**，即可立即在模拟器与真机预览中测试上传。

### 第 2 步：在微信公众平台修改类目与隐私指引（替代原游戏项目必做）
登录 [微信公众平台 (mp.weixin.qq.com)](https://mp.weixin.qq.com)：
1. **服务类目调整**（避免再次因“涉及游戏”被拒）：
   - 进入 **设置 -> 基本设置 -> 服务类目**，删除与游戏相关的类目，改为 **`工具 -> 效率`**（或 `工具 -> 办公` / `工具 -> 备忘录`）。
   - 如小程序名称或简介中仍残留 `bounce`、识字闯关、游戏等字样，请同步修改为工具定位（如文件归档传送工具）。
2. **配置《用户隐私保护指引》**（调用相册必配，否则真机正式版无法选视频）：
   - 进入 **设置 -> 基本设置 -> 服务内容声明 -> 用户隐私保护指引** -> 点击更新：
   - 勾选收集项：**“选中的照片或视频信息”**（用途填写：`用于用户主动选择本地视频文件进行传输与重命名归档`），保存并等待约 5 分钟生效。

### 第 3 步：体验版 vs 正式版域名说明（重要！）
- **方案 A：直接使用【体验版】（无需备案域名，最快最省心）**
  1. 在微信开发者工具点击右上角 **上传**，上传新版本代码。
  2. 在微信公众平台 **管理 -> 版本管理** 中，将该版本设为 **体验版**（可在 **成员管理 -> 体验成员** 中添加最多 15~50 个微信号）。
  3. 体验成员首次扫码进入小程序后，点击右上角 `...` -> **打开调试**（开启一次后自动重启进入开发调试态，即可直接连接未备案的 `https://dance.lage.us.ci` 稳定上传）。
- **方案 B：提交微信审核发布【正式版】**
  1. **合法域名备案要求**：微信公众平台后台 `开发管理 -> 开发设置 -> 服务器域名 -> request合法域名` 强制要求填写**已完成国内工信部 ICP 备案**的 HTTPS 域名（`.us.ci` 未备案域名无法填入微信后台白名单）。若您有已备案域名，只需将其绑定/反代到该 Cloudflare Pages 项目，并修改 `miniprogram/config.js` 中的 `API_BASE_URL` 即可。
  2. **提交审核备注技巧**：提交审核时，在“测试账号/审核备注”栏务必提供测试访问口令（或临时测试口令），并注明：`本工具为内部文件命名归档传输效率工具，测试访问口令：xxxx`。另外注意个人主体小程序对视频类功能审核较严，纯内部使用优先推荐【体验版】。
